🔐 Modern Login Page

A simple and modern Login Page created using HTML and CSS.
This project is designed with a clean interface and responsive layout.

✨ Features

- 🔑 Username and password fields
- 👁️ Password input
- 🔵 Modern and clean design
- 📱 Responsive layout
- 🎨 Simple user-friendly interface

🛠️ Technologies Used

- HTML5
- CSS3

📂 Project Structure

login-page/
│
├── index.html
├── style.css
└── README.md

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. The login page will appear.
